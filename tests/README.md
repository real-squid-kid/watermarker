# Проверки

Проекты тестов именуются `WaterMarker.<Module>.Tests` и добавляются в `WaterMarker.slnx`.
`scripts/Verify.ps1` запускает все проекты `*Tests.csproj` в этом каталоге после сборки решения.

Модульные тесты проверяют правила проектов, генерацию кодов и расчёт раскладки.
Интеграционные тесты используют отдельную временную SQLite и проверяют транзакции,
публикацию без перезаписи и восстановление после сбоев. WPF-проверки выполняются в STA.
Тесты FFmpeg отделяются от проверок, не требующих видео.

Материалы с личными данными хранятся в `tests/Fixtures/Private` или `test-data`;
оба каталога исключены из Git. Публичные фикстуры должны быть синтетическими.
Результаты и доказательства ручной приёмки сохраняются в локальном `.local/acceptance`.
